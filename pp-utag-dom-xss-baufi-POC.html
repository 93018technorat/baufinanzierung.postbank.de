Postbank baufinanzierung.postbank.de — cross-origin DOM XSS PoC

The page's Adobe Launch tag has a postMessage listener with no origin check: any site can send it data, which lodash 4.17.5 mergeWith deep-merges — a constructor.prototype payload pollutes Object.prototype.utag_data. The tag then reads that polluted utag_data.product_name and writes it unescaped into a retargeting tag via document.write, so an attacker-controlled <img onerror> runs in the baufinanzierung.postbank.de origin.
